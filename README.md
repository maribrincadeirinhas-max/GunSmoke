# Gunsmoke 3D

## Sobre o projeto

Este projeto consiste em uma versão 3D do jogo **Gunsmoke**, desenvolvido com o objetivo de reproduzir e adaptar a experiência do jogo original em um ambiente tridimensional.

A proposta é explorar o desenvolvimento de jogos em 3D, implementando mecânicas de movimentação, combate e outros elementos presentes na experiência do jogo.

## Objetivo

O objetivo do projeto é desenvolver uma versão 3D inspirada em Gunsmoke, colocando em prática conhecimentos de programação e desenvolvimento de jogos.

## Funcionalidades

* [ ] Movimentação do jogador
* [ ] Sistema de tiro
* [ ] Inimigos
* [ ] Sistema de vida
* [ ] Cenário em 3D
* [ ] Sistema de pontuação

*As funcionalidades serão atualizadas conforme o desenvolvimento do projeto.*

## Tecnologias utilizadas

* **Engine:** Godot 4.5
* **Linguagem:** GDScript
* **Modelagem 3D:** Blender 5.2
* **Textura:** GIMP 3.2

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/maribrincadeirinhas-max/GunSmoke.git
   ```
2. Abra o projeto na engine utilizada.
3. Execute o jogo.
